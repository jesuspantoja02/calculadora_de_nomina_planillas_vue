# Frontend — Vue.js

SPA **Vue 3 + Vite + Vue Router** que consume la API Express de nómina.

```
frontend/     # Vue 3 → http://localhost:5174
```

Habla con `backend/` en `http://localhost:3000` (`/api/v1` vía proxy de Vite).

## Ejecutar

Desde la raíz del monorepo (con el backend ya levantado):

```bash
npm run dev:frontend
```

O desde aquí:

```bash
npm install
npm run dev
```
